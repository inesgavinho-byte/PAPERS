# Boundaries

What this discipline is not. A discipline is defined as much by what it refuses as by what it claims.

**AI-Native Organisational Architecture is not:**

**Enterprise Architecture.** Enterprise Architecture maps systems onto business functions; it takes the organisation as given. This discipline takes the organisation itself as the object of design.

**Management Consulting.** Consulting sells recommendations and leaves. This discipline designs structures that observe, remember and learn after the architect is gone.

**Knowledge Management.** Knowledge Management stores. Storage is not memory: storage accumulates; memory returns.

**AI Strategy.** AI Strategy asks where to apply a technology. This discipline asks what an organisation must be so that intelligence — human or artificial — compounds instead of dissipating.

**Software Architecture.** Software is implementation, not architecture. Architecture precedes construction, exactly as in buildings.

**Digital Transformation.** Transformation programmes change tools and call it change. Tool ≠ Architecture.

---

A test for any future ambiguity: if the work could be completed without observing the organisation first, it belongs to one of the fields above — not to this one.
