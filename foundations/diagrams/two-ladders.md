# Diagram — The Two Ladders of the Discipline

This is the specification for the discipline's principal diagram. It is text, not an image, so that it can be regenerated faithfully and corrected. The final published version must be **SVG**, not a raster export — raster loses legibility at scale and cannot be corrected in place.

Every string below is verified against the closed Canon (Dialogues 001–004). If a future edit to the diagram disagrees with this file, this file — and behind it the Canon — is authoritative.

## Composition

Three zones on one plane, plus footer.

- **Left — Ontological Ladder** (*the order of being*): six stacked levels, top to bottom.
- **Right — Realisational Ladder** (*the order of coming-to-be*): three stacked levels, top to bottom.
- **Centre — Pattern**: a single circle, the shared axis of both ladders. Not a bridge between them; the axis they both turn on.
- **Below centre — Fundamental Dualities**, then the **Depth Rule**.

Aesthetic: PAPERS palette — warm off-white ground, ink text, a single discreet olive accent (#8b8670) reserved for the Pattern circle and the connectors. Typography carries the interface; whitespace is information. No SaaS colour, no shadows, no gradients.

## Left ladder — exact content (title · gloss)

1. Structure *(primitive)* · parts organised in relation
2. System · a structure that preserves a pattern despite change, independently of the particular agents involved
3. Living system · a system that preserves its constitutive pattern
4. Organisation · a living system whose constitutive pattern includes a shared purpose across time
5. Enterprise · an organisation that sustains its purpose through the creation of economic value
6. Company · a legal form through which an enterprise operates

Caption beneath: *The invariant runs through the whole ladder: each level specifies the invariant of the level below.*

## Centre — Pattern

Circle. Title **Pattern**. Definition: *what stays the same when the particulars change.* Beneath, quieter: *The invariant at the heart of every system. It is what is preserved.*

Caption: *The centre of the discipline. Everything in the Canon can be expressed in terms of Pattern. It is the axis that both ladders share.*

Two dashed connectors ("is preserved by / underlies"): one from the **System** box (left) to the circle — the system is what preserves the pattern; one from the **Principle** box (right) to the circle — principle and pattern are the same thing seen from the realisational side. The left connector must originate at System, not at Structure or Company.

## Right ladder — exact content

1. Principle *(Pattern)* · what must be preserved
2. Architecture *(implementation)* · creates the conditions under which the pattern can persist *(observes, remembers, decides, learns)*
3. Form *(manifestation)* · the concrete embodiment that can change

Caption beneath: *Many forms can express the same pattern through the same architecture. Form changes. Pattern endures.*

## Fundamental Dualities — exact content

Four pairs. **Each pair carries its own gloss.** They do NOT sit under a single column header such as "what remains / how it remains" — only the first and third pairs are *what/how*; the second is *fixed/variable*. Forcing all four under one header is the recurring error in earlier drafts and must not be repeated.

- Pattern / System — *what remains · how it remains*
- Identity / Transformation — *what is fixed · what may vary*
- Structure / Architecture — *what exists · how it is kept*
- Principle / Implementation — *the what · how it is decided*

## Depth Rule — exact content

*The Canon descends only as far as the discipline requires. A deeper primitive that changes no definition above it is noted, not adopted. Knowing where to stop is itself a discipline. (Pattern rests on distinction/difference — Spencer-Brown, Bateson — but that floor lies outside the discipline's boundary.)*

## Legend

- Solid arrow: *depends on / emerges from*
- Dashed arrow: *is preserved by / underlies*

## Scope note

This diagram shows only what is **closed** in the Canon: the four derived definitions, the two ladders, the derived dualities, the depth rule. It must NOT include the method cycle (Observe → Memory → Judgement → Architecture → Evolution) as if those were closed — Observation, Memory, Judgement and Evolution are not yet derived. A diagram that mixes closed definitions with undrawn hypotheses misrepresents the state of the discipline. Keep the map to the foundation; the programme belongs elsewhere.
