# Foundations

The epistemological infrastructure of the discipline behind PAPERS.

This directory is **not built and not published**. It lives in the repository, versioned beside the site it governs, but outside `src/content/` — so Astro never renders it. It is the private ground from which the public Papers are derived.

## What is here

**Foundation documents** — these *discover*:

- `000-canon.md` — the closed definitions. What is true within the discipline. Contains the rules of entry, the five tests, the Ladder, the Ladder of Realisation, and the Dualities.
- `001-glossary.md` — every term the discipline depends on, marked *closed*, *provisional* or *pending*.
- `002-axioms.md` — the truths that do not change; the reserved block for Structural Laws.
- `003-boundaries.md` — what the discipline is *not*.
- `004-method.md` — the two sequences (engagement and inquiry), the invariant operator, the Foundation/Derived distinction, the three conceptual layers.
- `005-editorial-protocol.md` — how Papers are written; the rules against machine-made prose; the five editorial tests.
- `006-hypotheses.md` — the holding pen: Paper ideas awaiting the concepts they depend on.
- `dialogues/` — the Socratic record of how each definition was derived, including the rejected formulations and why. Dialogues 001–004 are closed.
- `diagrams/` — specifications for canonical diagrams (text, not images, so they can be regenerated in SVG).

## How to read it

Start with `000-canon.md`. It is short by design. The Ladder (structure → system → living system → organisation → enterprise → company) is the spine; every definition specifies the invariant of the level below.

The dialogues are the reasoning; the Canon is the conclusion. If a definition ever seems arbitrary, its dialogue explains why it beat the alternatives.

## The one rule

Nothing enters the Canon without surviving a dialogue. A Paper may use the foundation but never silently amend it — if writing reveals a gap, the writing stops and a dialogue opens. This is what keeps the body of work coherent as it grows: many Papers, one foundation.
